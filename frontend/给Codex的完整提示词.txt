## E. 真实图片生成——接 OpenAI DALL-E

新建 backend/app/providers/openai_image_provider.py，继承 BaseImageProvider：

- provider_key = "openai"
- get_model_list() 返回 dalle-3，status 根据 openai_api_key 是否配置来定
- generate_image() 调 openai.images.generate，参数 prompt/size/n=1/response_format=b64_json，结果解码 base64 写入 output_dir，返回 ProviderResult（url 用 public_base_url/storage/xxx）
- estimate_cost() 返回 80（2048分辨率）或 50（1024）

在 backend/app/providers/__init__.py 中导出 OpenAIImageProvider。

在 backend/app/core/provider_router.py 的 _register_defaults() 中，用 OpenAIImageProvider() 替换旧的 dalle provider。

在 backend/pyproject.toml 的 dependencies 加 "openai>=1.0"。

## F. AI 对话接真实 LLM

修改 backend/app/services/conversation_service.py，新增 stream_chat(conversation_id, user_content) 方法：

1. 查 chat.conversation_messages 拿最近 20 条历史
2. 拼 messages = [{"role": row["role"], "content": row["content"]} ...] + {"role":"user","content": user_content}
3. 调 openai.chat.completions.create(model="gpt-4o-mini", messages=messages, stream=True)
4. 收集完整回复文本，写入 chat.conversation_messages
5. async generator yield SSE: data: {"token":"xxx"}\n\n

backend/app/routers/conversations.py 新增 POST /{conversation_id}/stream 路由，返回 StreamingResponse(content_type="text/event-stream")。

前端 frontend/app/chat/page.tsx 改 send 函数：
- 没有对话时先 POST /conversations 创建
- POST /conversations/{id}/stream 带 {content: userInput}
- 用 fetch + reader.read() 解析 SSE
- 逐 token 追加到消息列表（打字效果）
- 发送中 input 禁用、按钮 loading
- ChatMessageList 加 useEffect + useRef，新消息时 scrollTo bottom

ChatMessageList.tsx：加 `const bottomRef = useRef<HTMLDivElement>(null)` 和 `useEffect(() => bottomRef.current?.scrollIntoView({behavior:"smooth"}), [messages])`，在消息列表末尾放 `<div ref={bottomRef} />`。
